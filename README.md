Monday Morning Punchlines — one joke about Monday mornings, judged two at a time by a stand-up comic.

## The entry

> Monday's alarm went off and I snoozed it so hard the snooze button asked for the weekend off too.

97 characters, one line, plain ASCII — inside the 1–200 character gate.

## Why this line

Written against the judge's brief, in the order it weighs things:

1. **On subject** — a joke about Monday mornings: the alarm, the snooze, the weekend just lost.
2. **Real laugh, not a complaint** — nothing is listed as wrong with Mondays; the laugh comes from the turn, when the snooze button itself joins the strike.
3. **Surprise** — the twist is not the first thing anyone would think of: the button built to absorb the abuse asks for the weekend off too, so the exhaustion spreads from the human to the machine.
4. **Few words, every word working** — one sentence, no wasted setup; the punchline lands in the last four words.
5. **Fresh** — it dodges the tired "I hate Mondays" and "coffee first" cliches.
